# 正式证据规律

V0 将证据链稳定、口径经后续验收保持一致的规律设为默认。数字来自29个账号、203篇文章（高表现145、普通对照58）的第四轮研究；它们表示样本关联，不证明因果。

## R02｜多重标题钩子叠加

- 适用范围：全主题；尤其适合需要快速说明“谁、遇到什么、能得到什么”的文章。
- 使用方式：从身份、场景、问题、结果、反差、风险、步骤中选2—3种。标题必须由正文兑现。
- 支持证据：高表现43/145（29.7%），普通文11/58（19.0%），覆盖19个账号；审计确认数字与等级在研究文件间一致。
- 使用强度：默认规则。
- 限制：不是钩子越多越好；不使用空泛情绪词和确定性承诺。

## R06｜命理知识承担现实解释功能

- 适用范围：八字、婚恋、事业、运势等需要专业知识的内容。
- 使用方式：每个核心术语都至少完成一次“术语/依据 → 现实含义”，必要时再加判断边界或行动意义。
- 支持证据：高表现79/145（54.5%），普通文25/58（43.1%），覆盖27个账号；审计确认数字与等级一致。
- 使用强度：默认规则。
- 限制：不要求术语出现在固定位置；专业词数量不等于解释质量。

## 不升级为正式默认的项目

- R01结果词、R03第二人称：保留为条件性标题工具，不声称普遍有效。
- R04女性关系共鸣：后续验收发现DEF-RES系统性漏判，移入实验区。
- 数字/步骤标题、互动结尾、短正文、咨询承接：现有证据不足或方向不支持，不能包装成“爆款公式”。
