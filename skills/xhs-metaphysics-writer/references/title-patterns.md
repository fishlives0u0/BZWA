# 标题机制

## 默认机制

先提取四项：主主题、目标读者、当前最关心的问题、文章真实能交付的结果。再从下列机制中组合2—3项：

- 身份：你、女生、某类日主、某种关系中的人。
- 场景：分手后、断联中、关系反复、正缘出现前。
- 问题：还会回来吗、为什么总联系、怎么看。
- 结果：复合可能、伴侣特征、时间变化、判断方法。
- 冲突：想靠近却更冷淡、分开了仍联系。
- 反常识：逢合不等于复合、放不下不等于正缘。
- 风险/边界：别只看一个宫位、先别急着下结论。
- 步骤：两步判断、先看A再看B；仅在正文真有步骤时使用。

“同一标题叠加两种以上机制”是V0的正式默认规则。研究样本中，高表现43/145，普通文11/58，覆盖19个账号。它指导机制组合，不要求套固定句式。

## 每次生成3—5个不同标题

尽量覆盖以下不同方向，而不是把同一句换几个词：

1. 直接问题型：`分手后，他还会回来吗？先看这三个信号`
2. 结果/判断型：`能不能复合，真正要看的不是“还爱不爱”`
3. 场景型：`断联很久又突然点赞，这种关系为什么总会回头`
4. 反常识型：`夫妻宫逢合，不等于一定会复合`
5. 女性视角型：`你放不下的，可能不是他，而是这段关系没说完`

选推荐标题时说明一句理由，例如“它同时包含场景、问题与判断边界，且正文能够兑现”。

## 条件机制

- 结果词：适合读者确实关心明确结果的婚恋、事业、运势选题；不能许诺正文无法证明的结果。
- 第二人称：适合能明确指向读者的内容；不要每个标题都用“你”。
- 数字/步骤：不是默认爆款技巧。只有正文确实有清晰步骤或清单时才用。

## 禁止

- “看完吓一跳”“太准了”“必看”“99%的人不知道”等空泛刺激词。
- 一定、注定、百分百、必复合、必发财等确定性承诺。
- 标题承诺“看时间/看结果”，正文却只讲泛泛性格。
- 连续文章重复同一句式；参照 `anti-repetition.md` 轮换机制组合。
