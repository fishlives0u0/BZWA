# 文章结构库

结构来自冻结的DEF-STRUCT-02。203篇均做逐节点源证据核验，200篇可验证，28篇形成至少一种完整结构。只有四节点均成立且顺序正确的结构才算完整；标题、标签、CTA或单个术语不能代替正文节点。

## 结构A｜现实场景切入（研究结构01）

现实场景或提问 → 明确读者对号入座 → 原因解释 → 判断或建议。

- 适合：复合、冷淡、反复联系、关系困惑；也适合把抽象命理问题落到生活场景。
- 长度：400—650字。
- 命理位置：读者处境说清后进入。
- 结尾：给判断边界或现实建议。
- 已验证完整样本：7篇。代表S085《能陪你走到最后的正缘…》、S059《什么样的灵魂，会在这一世选择身弱的剧本》、S009《男坏女安心理解析》。

## 结构B｜直接结论（研究结构02）

明确结论 → 命理或专业依据 → 现实映射 → 结论收束。

- 适合：反常识纠偏、明确判断、专业信任。
- 长度：450—750字。
- 命理位置：结论之后立即给依据。
- 结尾：重复边界，不重复口号。
- 已验证完整样本：8篇。代表S106《如何知道自己什么时候结婚》、S065《夫妻宫是最特殊的宫位》、S115《你的地支中有“丑”么？》。

## 结构C｜关系/人群特征（研究结构03）

明确人群 → 至少两个具体特征 → 命理归因 → 风险或机会提醒。

- 适合：伴侣画像、关系特征、某类命盘表现。
- 长度：420—650字。
- 命理位置：特征之后，用来解释为何出现这些表现。
- 结尾：提醒读者不要用单一特征给人定性。
- 已验证完整样本：3篇。代表S127《占有欲太强的八字》、S061《男朋友有这个特征，注意是妈宝男》、S012《我看到的安坏真相：男坏是纸老虎》。

## 结构D｜时间节点（研究结构04）

明确时间节点 → 至少两个运势分项 → 风险/机会判断 → 行动清单。

- 适合：月运、流年、阶段运势。
- 长度：450—700字。
- 命理位置：时间节点后解释分项变化。
- 结尾：给“做什么/不做什么”，不把概率写成必然。
- 已验证完整样本：5篇。代表S100《9月庚金｜别问原因，照做就对了》、S103《8月癸水｜别瞎卷！越努力越废》、S034《白露一过｜丁酉月来了》。

## 结构E｜女性成长关系（研究结构05）

具体情绪痛点 → 关系模式 → 自我理解/去自责解释 → 边界或安慰。

- 适合：反复爱上同类人、越谈越累、依恋与自我价值。
- 长度：500—750字。
- 命理位置：用于解释模式，不用于替读者做决定。
- 结尾：具体边界或选择，不写空泛鸡汤。
- 证据状态：冻结定义完整，但14校准版中没有主结构05的完整样本。V0可把它作为谨慎的设计模板，不得称为高表现规律。

## 结构F｜命理知识教学（研究结构06）

明确教程问题 → 概念/规则 → 至少两个操作步骤 → 复查或总结。

- 适合：夫妻宫怎么看、合冲刑害怎么判断、入门教学。
- 长度：550—850字。
- 命理位置：主体。
- 结尾：给复查顺序和常见误区。
- 已验证完整样本：1篇，S069《旺弱完全是误人子弟》。样本很少，使用时重视逻辑完整，不宣称表现优势。

## 结构G｜案例型（研究结构07）

具体案例主体 → 可识别冲突 → 命理解释 → 结果判断。

- 适合：有真实、匿名化案例资料时。
- 长度：550—850字。
- 命理位置：冲突之后，解释关键节点。
- 结尾：提炼可迁移判断；不能编造“客户案例”。
- 已验证完整样本：1篇，S110《一字毁全局之做工的干扰星》。没有真实案例素材时改用结构A或B。

## 结构H｜观点型（研究结构09）

明确观点 → 经验或理由解释 → 价值判断 → 收束。

- 适合：轻内容、关系观点、自我认知、行业观察。
- 长度：350—600字。
- 命理位置：可作为一种理由，不必强行成为主体。
- 结尾：一句清晰价值判断或边界。
- 已验证完整样本：3篇。代表S155《关于正缘的见解（上）》、S190《同一个八字：有人年薪40万，有人12万》、S157《7个让别人更容易答应你的心理技巧》。

## 选择规则

- 结果纠偏优先B；教学优先F；时间运势优先D；有真实案例优先G。
- 具体关系处境优先A；特征画像优先C；女性自我理解优先E；轻观点优先H。
- 每次给一个备选结构，且备选必须改变文章推进，不只是换标题。
- 结构与流量/信任/转化的自动搭配尚未通过校准，不作正式路由。
